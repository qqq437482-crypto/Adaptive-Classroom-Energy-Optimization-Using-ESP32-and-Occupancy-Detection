# Adaptive Classroom Energy Optimization

## Overview
This project is an ESP32-based smart classroom system designed to reduce energy consumption by automatically controlling classroom devices based on occupancy and environmental conditions.

## Features
- Student counting using dual IR sensors
- Temperature monitoring using DHT22
- Automatic fan control
- LCD real-time display
- Energy-saving operation
- Web dashboard monitoring

## Hardware
- ESP32
- DHT22
- 2 IR Sensors
- Relay Module
- LCD I2C
- LEDs

## Future Improvements
- AI-based energy prediction
- Student focus estimation
- Classroom analytics dashboard
